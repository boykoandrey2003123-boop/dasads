# BuildBattle Plugin (1.21, Paper API)

## Сборка

Нужны: JDK 21, Maven, интернет (для загрузки Paper API из repo.papermc.io).

```bash
cd buildbattle
mvn clean package
```

Готовый файл: `target/BuildBattle.jar`. Положить в `plugins/` на Paper-сервере 1.21.x.

## Первый запуск

1. Дайте себе право `buildbattle.admin` (по умолчанию есть у OP).
2. Напишите `/bb` → откроется меню → «Админ-панель» → «Создать арену».
3. Введите имя арены в чат.
4. В открывшемся мастере: «Выдать инструмент выделения» → ЛКМ по блоку = точка 1, ПКМ по блоку = точка 2 (это будет внешняя граница ячейки, включая стены). Стены — 1 блок по X/Z с каждой стороны, они защищены от слома.
5. «Добавить ячейку из выделения» — повторить минимум 2 раза (для 2+ ячеек в арене).
6. «Завершить и сохранить арену».
7. Игроки: `/bb` → «Играть» → выбрать режим (Соло/Двое/Трое) → дождаться набора игроков.

## Настройки

`plugins/BuildBattle/config.yml` — время постройки, время показа при оценке, список тем (рус.), блоки для заливки, названия и очки оценок.
`plugins/BuildBattle/arenas.yml` — сохранённые арены (генерируется автоматически, руками редактировать не обязательно).

## Важное замечание

Этот код собирался и проверялся вручную построчно в среде без доступа в интернет и без установленного Maven/Paper API, поэтому реальная компиляция (`mvn clean package`) не выполнялась. Логика и API-вызовы выверены по документации Paper 1.21, но если при сборке всё же вылезет ошибка компиляции — пришлите текст ошибки, и я быстро её поправлю.
